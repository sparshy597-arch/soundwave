Hey! This is my web app SONORA, a music visualizer I made because I wanted to try something different with music. You can upload your favourite songs and see the visuals move according to the beats and sound. It's a small project, but I really enjoyed making it and working on the little details.
If you want to run it on your PC, just download or clone this repository, open the folder and run `index.html` in your browser. You can also use Live Server in VS Code.
You can check it out here: https://sparshy597-arch.github.io/soundwave/
Hope you like it!
